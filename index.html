شرح تثبيت مشروع Ollama

🔰 ما هو Ollama؟

مشروع Ollama هو برنامج مفتوح المصدر يسمحلك بتشغيل موديلات ذكاء اصطناعي محليًا على جهازك سواء موبايل أو كمبيوتر. مفيد للمطورين أو الناس اللي بتحب تجرب موديلات AI بدون الحاجة لاتصال دائم بالإنترنت.

📱 التثبيت على الموبايل (Termux)

  1. فتح Termux وكتابة التالي لتحديث الحزم:
    2. pkg upgrade
  2. تثبيت الأدوات المطلوبة:
    3. pkg install git cmake golang
  3. تحميل المشروع من GitHub:
    4. git clone --depth 1 https://github.com/ollama/ollama.git
  4. الدخول للمجلد وبناء المشروع:
    5. cd ollama
go build .
  5. تشغيل الموديل:
    6. ./ollama run deepseek-r1:1.5b --verbose

💻 التثبيت على الكمبيوتر (Linux)

  1. تأكد إن Go و Git و CMake متثبتين:
    2. sudo apt update && sudo apt install git cmake golang
  2. تحميل المشروع:
    3. git clone --depth 1 https://github.com/ollama/ollama.git
  3. الدخول للمجلد:
    4. cd ollama
  4. بناء المشروع:
    5. go build .
  5. تشغيل موديل الذكاء الاصطناعي:
    6. ./ollama run deepseek-r1:1.5b --verbose

🪟 التثبيت على ويندوز

  1. حمّل Git for Windows
  2. نزّل Golang وثبّته.
  3. افتح Git Bash أو CMD:
    4. git clone --depth 1 https://github.com/ollama/ollama.git
cd ollama
go build .
./ollama run deepseek-r1:1.5b --verbose
